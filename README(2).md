## Objective

The objective of this task is to perform data cleaning and exploratory data analysis on the Titanic dataset.

## Work Performed

- Loaded and inspected the Titanic dataset
- Checked dataset shape and structure
- Identified missing values
- Handled missing Age values using the median
- Handled missing Embarked values using the mode
- Removed the Cabin column because of a large number of missing values
- Detected and handled Fare outliers using the IQR method
- Created visualizations for exploratory data analysis
- Analyzed survival based on passenger characteristics
- Studied relationships between Survival, Sex, Passenger Class and Age
